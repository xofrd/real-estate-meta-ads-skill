# Security · Segurança

## English

This repository contains text instructions only, but they guide an AI that may have access to real ad accounts and money.

**Never post tokens or account data.** Do not paste Meta access tokens, app secrets, ad account IDs, business IDs, lead data or screenshots with personal data in issues, pull requests, commits or discussions. If you posted one by mistake: revoke or rotate the token in Meta immediately, then ask a maintainer to remove the content.

**What to report privately:** instructions in the skill that could lead Claude to change an account without confirmation, spend more than intended, expose a token or personal data, or bypass Meta's policies.

**How to report:** use GitHub's private vulnerability reporting ("Security" tab → "Report a vulnerability"). Please do not open a public issue for these. We will acknowledge as soon as we can; this is a volunteer project with no guaranteed response time.

## Português (Brasil)

Este repositório tem só instruções em texto, mas elas orientam uma IA que pode ter acesso a contas de anúncio reais e a dinheiro.

**Nunca publique token ou dado de conta.** Não cole token de acesso da Meta, segredo de app, ID de conta de anúncios, ID de empresa, dado de lead ou captura de tela com dado pessoal em issues, pull requests, commits ou discussões. Se publicou por engano: revogue ou troque o token na Meta na hora e peça a um mantenedor para remover o conteúdo.

**O que relatar em privado:** instruções da skill que possam levar o Claude a mudar uma conta sem confirmação, gastar mais que o combinado, expor token ou dado pessoal, ou contornar as políticas da Meta.

**Como relatar:** use o relato privado de vulnerabilidade do GitHub (aba "Security" → "Report a vulnerability"). Não abra issue pública para isso. Responderemos assim que possível; é um projeto voluntário, sem prazo garantido.
